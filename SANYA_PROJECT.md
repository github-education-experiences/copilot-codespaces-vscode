# 🌸 For Sanya - Valentine's Day Proposal Website

This repository now contains a complete, romantic Valentine's Day proposal website built for Sanya Tripathi.

## 📁 Project Location

The Valentine's proposal website is located in the `/for-sanya` directory.

## 🚀 Quick Start

```bash
cd for-sanya
npm install
npm run dev
```

Then open http://localhost:3000

- **README**: `for-sanya/FOR_SANYA_README.md` - Installation and usage guide

## 🎯 What's Inside

A complete full-stack romantic proposal website with:

- ✅ 6 interactive pages with smooth animations
- ✅ Heart-catching mini game
- ✅ Typewriter effect love letter
- ✅ Playful YES/NO proposal buttons (NO button runs away!)
- ✅ Confetti celebration
- ✅ Admin dashboard to track responses
- ✅ MongoDB backend for storing responses
- ✅ Beautiful pink/red Valentine's theme
- ✅ Mobile-responsive design
- ✅ Ready to deploy to Vercel

## 🎨 Tech Stack

- **Frontend**: Next.js 15 + TypeScript + TailwindCSS v4
- **Animations**: Framer Motion + canvas-confetti
- **Backend**: Next.js API Routes + MongoDB
- **Deployment**: Vercel + MongoDB Atlas (free!)
